# MOBILE FIRST (REQUERIMIENTO MÁS IMPORTANTE)

La aplicación debe diseñarse completamente bajo una estrategia **Mobile First**.

Este es el requerimiento más importante del proyecto.

La mayoría de los usuarios abrirán la invitación desde:

- WhatsApp
- Facebook Messenger
- Instagram
- Telegram
- SMS

Más del 90% utilizará un teléfono móvil.

Por lo tanto:

- Diseñar primero para pantallas móviles.
- Toda la experiencia debe sentirse como una aplicación nativa.
- Los botones deben ser grandes y fáciles de tocar.
- Excelente legibilidad.
- Espaciado cómodo para el pulgar.
- Evitar bloques enormes de texto.
- Scroll natural.
- Excelente rendimiento en dispositivos de gama media.
- Optimizar la carga inicial.
- Las imágenes deben adaptarse correctamente.
- La navegación debe ser intuitiva desde el teléfono.

Después adaptar la experiencia a:

- Tablet
- Desktop

Desktop NO es la prioridad.

Mobile siempre tendrá prioridad sobre cualquier otra resolución.
